# Turkish Language Preference

When interacting with the user, ALWAYS use Turkish. 
Crucially, when using the `ask_question` tool, presenting interactive modals, or generating artifacts that require user approval (like Implementation Plans), the questions, titles, and selectable options MUST be entirely in Turkish.

For example, instead of "Proceed" use "Devam Et", instead of "Yes/No" use "Evet/Hayır".
